# Referências de Cartões de Visita

## Especificações AWT

| Campo | Valor |
|-------|-------|
| Dimensões | 340px × 190px por face |
| Formato | HTML (frente + verso) |
| Frente | fundo escuro (cor primária) |
| Verso | fundo branco/creme (#fafaf8) |

## Padrão Visual

**Frente (escura):**
- Fundo na versão escurecida da cor primária (20–30% mais escura)
- Logo centralizado
- Borda fina interna: 1px sólida, rgba mais claro (opacity 0.3–0.4), 8px de margem

**Verso (claro):**
- Nome do banker em destaque: 1rem, 600, #111
- Cargo: 0.75rem, uppercase, letter-spacing 0.1em, #666
- Linha divisória fina na cor primária: 20px
- Contatos: telefone + email
- Nome do escritório no canto inferior direito

## Como adicionar referência

Salve o HTML do cartão como `{slug}-card.html` nesta pasta.
