# Referências de Foto Corporativa

## Fluxo

**Com API OpenAI configurada:**
1. Banker faz upload da foto original (qualquer qualidade)
2. Painel envia para `gpt-image-1` com o prompt de transformação
3. API retorna PNG corporativo processado

**Sem API OpenAI:**
1. Banker faz upload da foto já tratada externamente
2. Painel usa diretamente
