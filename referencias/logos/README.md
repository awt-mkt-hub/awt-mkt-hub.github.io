# Referências de Logos

## Diretrizes AWT

Todos os logos AWT seguem as especificações:

- **Formato:** SVG, viewBox `0 0 320 90`
- **Layout:** ícone geométrico à esquerda, nome à direita
- **Fundo:** transparente
- **Estilo:** minimalista, geométrico, profissional

## Como adicionar um logo de referência

Adicione o arquivo `.svg` nesta pasta com o nome `{slug}.svg`.

Exemplo: `ll-wealth.svg`, `ftm-wealth.svg`
